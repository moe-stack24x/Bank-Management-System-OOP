# 🏦 Bank Management System (OOP)

A comprehensive banking system built with C++ using Object-Oriented Programming (OOP) principles. The project simulates real-world banking operations through a menu-driven interface and multiple management modules.

## 🌟 Features

### 👥 Client Management

* View client list
* Add new clients
* Update client information
* Delete clients
* Search for clients

### 💰 Transactions

* Deposit money
* Withdraw money
* View total balances
* Manage client accounts

### 🔐 User Management

* Add users
* Delete users
* Update user information
* User permissions system

### 📋 Login System

* Secure authentication
* Login register/history tracking

### 💱 Currency Exchange

* View currencies
* Find currencies
* Update exchange rates
* Currency conversion

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Classes & Objects
* Inheritance
* Encapsulation
* File Handling
* Multi-Screen Architecture

## 🚀 How to Run

1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
4. Login and start managing the system.

## 🎯 Learning Objectives

This project was developed as part of my C++ learning journey to practice building large-scale console applications using Object-Oriented Programming concepts and real-world software design techniques.
